# System Design Report (SRS)

## 1. Introduction
This Software Requirements Specification document describes the architecture and behavior of the **Post-Quantum Blockchain PHR Security** system.

## 2. Overall Description
The system provides a highly secure, tamper-proof repository for Personal Health Records (PHR) utilizing Lattice-based cryptography for post-quantum theoretical safety and smart contract immutability.

## 3. System Features
- **PQ Key Exchange:** Simulation or integration of Kyber/Dilithium algorithms for securing the symmetrical tunnel before transmitting PHR data.
- **Smart Contract Auditing:** Every read/write to an electronic health record emits a verifiable on-chain event.
- **Role-Based Access Control (RBAC):** Restricts data decryption to the specific patient and their authorized medical practitioners.

## 4. UI/UX Paradigm
The UI implements an "AI-generated" dark futuristic theme with heavy usage of glassmorphism, glowing accents, and fluid Framer Motion states, representing the bleeding-edge nature of the underlying tech stack.
